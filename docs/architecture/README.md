# THARA + Archify

Archify is integrated as THARA's architecture visualization layer.

- Source specifications live in `docs/architecture/*.json`.
- The Archify skill is available at `.agents/skills/archify/SKILL.md`.
- GitHub Actions validates and renders the checked specification into `public/archify/thara-architecture.html`.
- The interactive viewer is exposed at `/architecture`.

Upstream project: https://github.com/tt-a1i/archify

The generated diagrams are descriptive artifacts. They do not imply live infrastructure, authorization, physical execution, or production ownership.
